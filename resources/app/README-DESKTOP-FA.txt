حسابداری کافی‌نت تمشک — نسخهٔ دسکتاپ ویندوز ۱٫۵٫۴۳
====================================================

برنامهٔ آفلاین و تک‌دستگاهی برای Windows 10/11 x64 است. داده‌ها روی همان دستگاه و حساب ویندوز ذخیره می‌شوند.

راهنما و اعلان‌ها
-----------------
روی آیکن راهنما در نوار بالایی بزنید. صفحهٔ «اعلانات» تاریخچهٔ هشدارهای انقضا، سررسید و اعلان‌های نرم‌افزار را نشان می‌دهد. بررسی انتشار جدید به اینترنت نیاز دارد.

تنظیمات پنل مدیریت
------------------
تب «تم و چیدمان» شامل تم، چیدمان، فونت رابط و ظاهر ردیف‌هاست. تب «پیش‌فرض‌ها و قابلیت‌های اختیاری» شامل پیش‌فرض‌های فروشنده برای فاکتور، ساده‌سازی و قابلیت‌های اختیاری و ابزارک دسکتاپ است. تب «تاریخ‌ها» شامل نمایش تاریخ، تقویم ورود تراکنش/هزینه و تقویم پیش‌فرض گزارش‌هاست.

چاپ فاکتور
----------
در پیش‌نمایش فاکتور، جهت، اندازهٔ کاغذ و حاشیه را انتخاب کنید و از «چاپ / ذخیره PDF» استفاده کنید. رفتار نهایی باید با درایور و چاپگر مقصد آزمایش شود.

ساخت نصاب در Windows
--------------------
در ریشهٔ سورس `npm ci` و سپس `npm run dist:win` را اجرا کنید؛ Node.js LTS و NSIS 3 یا جدیدتر لازم است. خروجی نسخهٔ جاری در `dist/حسابداری تمشک-Setup-1.5.49-x64.exe` است.

ساخت فعلی امضای Authenticode ندارد. هش SHA-256 کنار نصاب فقط تغییر ناخواسته را تشخیص می‌دهد و جای امضای ناشر را نمی‌گیرد. پیش از استفاده از داده‌های اصلی پشتیبان بگیرید.

آزمون‌ها:
```sh
node --test desktop/*.test.cjs resources/app/*.test.js resources/app/*.test.cjs
```
