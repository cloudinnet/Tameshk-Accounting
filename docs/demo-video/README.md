# Demo video assets / فایل‌های ویدیو / ملفات الفيديو

The main repository README contains one shared demo-video section at the very top for all three languages. When the recording is ready, place a thumbnail or supporting assets in this folder and update that single section with a real video URL.

بخش معرفی ویدئویی فقط یک‌بار و در ابتدای README اصلی آمده است و برای هر سه زبان مشترک است. پس از آماده‌شدن فیلم، تصویر بندانگشتی یا فایل‌های جانبی را در این پوشه قرار دهید و همان بخش را با پیوند واقعی ویدیو به‌روزرسانی کنید.

يظهر قسم الفيديو مرة واحدة فقط في بداية ملف README الرئيسي، وهو مشترك بين اللغات الثلاث. عند تجهيز التسجيل، ضع الصورة المصغرة أو الملفات المساندة في هذا المجلد وحدّث ذلك القسم برابط فيديو حقيقي.
